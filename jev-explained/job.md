# job.md — the "design inputs" the lesson system needs

You asked the system to produce a custom lesson system, not a worksheet. These
six inputs are what it needs to match content to YOUR class. Fill them in —
each one maps 1:1 to a section of the planner.

## 1. Learning goal
Clarifies what success looks like so the system can align every part of the lesson.

> Write one outcome sentence. "By the end, a learner can ______ ."

## 2. Prior knowledge
Reveals what learners already know so the system can build on it and avoid gaps
and repetition.

## 3. Learner profile
Shares who your learners are so the system can match content and approaches to them.

## 4. Lesson sequence
Sets the flow and pacing so the system can organize learning in a logical,
manageable way.

## 5. Learning activities
Names the tasks learners will do so the system can choose the right activities
to meet the goal.

## 6. Output requirements
Specifies the formats and constraints so the system delivers exactly what you
need, ready to use.

## 7. Assessment evidence
Defines how learning will be shown so the system can build matching checks for
understanding.

## 8. Accessibility & supports
Highlights needs and supports so the system plans inclusive options for every
learner.

## 9. Teacher decisions
Shares your preferences and priorities so the system adapts to your style and
context.
