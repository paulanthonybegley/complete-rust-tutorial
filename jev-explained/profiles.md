# profiles.md — nine learner profiles, one per design input

A good lesson system doesn't pick one average learner. It keeps nine profiles
in mind and checks each design input against the learner it worries about most.
Your class is not nine people — it's nine *worries*, and each input exists to
protect one of them.

| # | Input        | The learner it protects            | What the system must never do to them |
|---|--------------|-----------------------------------|---------------------------------------|
| 1 | Goal         | The Goal-Seeker — needs to know   | hand them busywork with no destination |
|   |              | what "done" looks like            |                                       |
| 2 | Prior        | The Starter — knows a little,     | repeat lesson 1 as if they know nothing|
|   | knowledge    | hides it                          |                                       |
| 3 | Profile      | The Different-One — learns        | teach to "the average student" (who    |
|   |              | differently but is rarely asked   | doesn't exist)                         |
| 4 | Sequence     | The Lost-Pacer — can do every     | front-load the whole lesson and hope   |
|   |              | step alone, fails if it's dumped  |                                       |
| 5 | Activities   | The Does-To-Learn — only          | lecture at them for ten minutes        |
|   |              | understands by doing              |                                       |
| 6 | Output       | The Deliverer — needs to produce  | leave the format open to interpretation|
|   |              | something concrete                |                                       |
| 7 | EES /        | The Rule-Keeper — wants to know   | grade by mood instead of agreed        |
|   | assessment   | exactly how they'll be checked    | criteria                                |
| 8 | Access &     | The Needs-Support — can do the    | design one path with no alternatives   |
|   | supports     | work with the right help          |                                       |
| 9 | Teacher      | The Decision-Maker — has the      | ignore their judgment and preset every |
|   | decisions    | context you don't                 | choice                                 |

## The one line that makes it a *system* and not a poster
**"Which learner does this input protect?"** — name the learner and you've
just told the AI what to optimize for. Leave them unnamed and the system will
optimize for a learner who does not attend your class.

## Using this file
In [worksheet.md](worksheet.md), each of the nine inputs has a row. Before you
hand a blank line to the machine, say which learner it protects. Then the plan
you get back is defending *someone you actually teach* — not an average that
doesn't exist.
