The point of the course

Ship the API. Zero → Hero.

The video builds a production marketplace and ships it. Our production API already exists — the api-rules app from the previous course, with 19 tests and versioned contracts. Everything below is the "acquisitions" arc applied to it.

The shipping loop

1

Containerize

Dockerfile, multi-stage, .dockerignore, health probe.

2

Pipeline

Every commit: test → package → scan → build & push the image.

3

Deploy

Kubernetes manifest with replicas, probes and rolling updates.

4

Watch

Health and metrics feed the loop back to plan — monitor, learn, repeat.

The kit, in four files

# 1 · image
docker build -f deploy/Dockerfile.api-rules -t api-rules:1.0.0 .
# 2 · verify locally
docker run --rm -p 8080:8080 -e API_VERSION_REQUIRED=true api-rules:1.0.0
curl -H "API-Version: 1.1" localhost:8080/products/1
# 3 · pipeline (GitHub Actions) tests + pushes on every commit
# 4 · manifest + IaC repeat the deploy on any cluster
kubectl apply -f deploy/k8s/api-rules.yaml
