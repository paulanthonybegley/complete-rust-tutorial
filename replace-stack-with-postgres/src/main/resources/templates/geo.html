PostGIS + GiST replaces standalone GIS / geocoding services

PostGIS is the gold standard for spatial data. Instead of running precise great-circle math over every coordinate on the planet, a GiST (Generalized Search Tree) index wraps each shape in a simple bounding box; the planner discards millions of far-away points instantly and only does the heavy geometry on the handful that remain. Below: 22 coffee shops around London, stored as geography(Point, 4326) and queried with ST_DWithin, the <-> k-NN operator and ST_Within.

Radius + nearest-first (k-NN)

SELECT name, rating,
       ST_Distance(location, ST_MakePoint(:lng, :lat)::geography) / 1000 AS distance_km
FROM coffee_shops
WHERE ST_DWithin(location, ST_MakePoint(:lng, :lat)::geography, :radius_meters)
ORDER BY location <-> ST_MakePoint(:lng, :lat)::geography;   -- k-NN via GiST

Point-in-polygon

SELECT name FROM coffee_shops
WHERE ST_Within(location::geometry, ST_GeomFromText(:wkt, 4326));   -- lon/lat order
