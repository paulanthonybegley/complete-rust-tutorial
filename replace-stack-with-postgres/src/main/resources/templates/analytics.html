Materialized views replaces Snowflake / data warehouses (for dashboards)

A normal view re-runs its aggregation from scratch on every hit — a dashboard dies under load. A materialized view runs the heavy query once and stores the result on disk. REFRESH MATERIALIZED VIEW CONCURRENTLY (which requires a unique index) recomputes in the background and hot-swaps the changed rows in without ever locking your dashboard readers.

The view + the refresh

CREATE MATERIALIZED VIEW mv_daily_sales AS
SELECT ordered_on, product,
       SUM(units) AS units, SUM(units * unit_price) AS revenue, COUNT(*) AS orders
FROM orders GROUP BY ordered_on, product;

CREATE UNIQUE INDEX idx_mv_daily_sales ON mv_daily_sales (ordered_on, product);

-- recompute in the background, swap rows in, never block readers:
REFRESH MATERIALIZED VIEW CONCURRENTLY mv_daily_sales;
