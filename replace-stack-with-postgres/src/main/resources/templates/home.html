One Postgres to rule your whole stack

Modern apps bolt on a dozen services — a document DB here, a cache, a message broker, a search engine, a vector store, a GIS server, a time-series DB and a data warehouse — most of which PostgreSQL already is. This is an interactive walkthrough of the features from The Coding Gopher's video "I replaced my entire stack with Postgres...", demonstrated live against a real Postgres 16 (+ PostGIS, pgvector, pg_trgm) instance running in Docker.
