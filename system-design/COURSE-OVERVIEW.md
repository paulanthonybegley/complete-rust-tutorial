## Teaching Approach

1. **Module-wise progression** — Don't skip lessons
2. **Active recall** — Close laptop and write notes from memory
3. **Hands-on diagrams** — Draw architecture for each system
4. **Trade-off analysis** — Always discuss pros/cons
5. **Peer review** — Present and defend designs

## Key Frameworks

### 6-Step Interview Framework
1. Clarify Requirements (10 min)
2. Estimate Scale (5 min)
3. Define Core Entities (5 min)
4. Design APIs (10 min)
5. High-Level Design (10 min)
6. Deep Dive (10 min)

### 5 Pillars of Great Design
1. Scalability
2. High Availability
3. Reliability
4. Efficiency
5. Manageability
