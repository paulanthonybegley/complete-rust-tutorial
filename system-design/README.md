# System Design Course

A comprehensive system design curriculum for classroom instruction.

## Course Structure

### Module 0: Foundations
- What is System Design
- Why it matters for software engineers
- HLD vs LLD overview

### Module 1: Building Blocks
- Servers, Databases, Caches
- Load Balancers
- CDNs (Content Delivery Networks)
- Message Queues

### Module 2: Scalability
- Vertical vs Horizontal Scaling
- When to use each approach
- Real-world examples (Netflix, Uber)

### Module 3: Data & Distribution
- SQL vs NoSQL databases
- Database replication
- Sharding & Partitioning
- CAP Theorem

### Module 4: Caching Strategies
- Browser caching
- Server-side caching (Redis, Memcached)
- Cache invalidation patterns
- Write-through, write-around, write-back

### Module 5: API Design
- REST APIs
- GraphQL
- gRPC
- API versioning and rate limiting

### Module 6: Real-World Systems
- Designing URL Shorteners
- Designing Chat Systems
- Designing Video Streaming (YouTube)
- Designing Ride Sharing (Uber)

## Teaching Approach
- Module-wise progression (don't skip lessons)
- Active note-taking and recall practice
- Hands-on architecture diagrams
- Trade-off analysis discussions
