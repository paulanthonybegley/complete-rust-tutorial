# Chapter 0: Why Programming Thinking Matters (Even With AI)
## From "Programming Thinking" by Visual Kernel — Walkthrough

### Learning Goal
Understand **why** programming thinking is essential in the age of AI, and set the mental framework for the rest of the course.

---

## 1. The core argument

The video opens with a bold, important claim:

> *"People say you don't need to write code anymore — you have AI. I actually agree with that. **But** if somebody says you don't need programming thinking because of AI, I couldn't disagree more."*

**Key idea:** Programming thinking ≠ writing code. Programming thinking is the **mental model** — variable, control flow, memory — that lets you *direct* AI effectively.

---

## 2. The "new common sense" analogy

To say programming thinking doesn't matter is like saying *basic knowledge and common sense don't matter*.

> We still learn math, science, and economics even though calculators and Google exist — **because they help us think and ask better questions.**

AI is an accelerator, not a replacement for understanding. You still need to:
- Know **what to ask**
- Spot **when the AI's output is wrong**
- Choose **which approach** will work

---

## 3. Vibe coding plateau vs programming-thinker growth

Two contrasting trajectories:
- **Pure "vibe coder"** (prompts AI without understanding): value **plateaus** over time. They can't debug, can't reason about edge cases, can't review the AI's code critically.
- **Programming thinker** (understands the mental model): can **harness AI's true potential** and build impactful projects that compound.

```
value |
      |    programming thinker   ╱
      |                        ╱
      |                      ╱
      |                    ╱
      |      vibe coder  ╱  ← flattened
      |                ╱
      |----------------┼────────────────────── time
```
